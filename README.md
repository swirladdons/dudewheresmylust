# Dude, Where's My Lust?
Shows a big alert when a boss pull starts and nobody has used Bloodlust, Heroism or a similar effect yet.

It can also alert on the first pull of a dungeon, and when the lust debuff runs out mid-fight. By default it only alerts characters that can lust.

The text, font, animation, sound and position are all customizable in the SwirlUI Core window under Lust Reminder.
